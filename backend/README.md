# Backend – FastAPI

This backend provides REST APIs for the AI-driven KYC onboarding system.

## Modules
- Authentication & roles
- Customer onboarding
- Workflow engine
- Audit logging
- OCR & NLP processing
- Risk scoring
- RAG compliance engine
- GenAI explanation

## Design Principles
- Modular architecture
- Role-based access control
- Explainable AI
- Regulatory compliance focus
